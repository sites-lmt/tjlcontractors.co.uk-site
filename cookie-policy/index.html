Cookie Policy

What this website stores in your browser, and why the answer is very little.

Last updated: 2026

The short version

This website does not set cookies and does not use analytics, advertising or tracking technologies of any kind. There is nothing to consent to, which is why you have not been shown a cookie banner.

Why we can say that

Cookies are small files a website asks your browser to store. They are usually set by javascript, by server-side session handling, or by embedded third-party services such as analytics platforms, advertising pixels or social media widgets.

This site does none of those things. It is a set of static pages. There is no login, no form, no comment system and no embedded media that would set anything in your browser. Our server does not set session cookies because there is no session to maintain.

Third-party requests

One third-party resource is loaded: the typefaces used on these pages are served by Google Fonts. This is a plain file request for a font, which does not set a cookie in your browser.

It does mean your IP address is transmitted to Google in order to deliver the font file. That is a technical necessity of serving it from their servers rather than ours, and it is the only outbound request this site makes. We do not receive or store any information from it. If you would prefer to avoid it, most browsers will let you block third-party font requests, and the site will still work — you will simply see a fallback typeface.

If that changes

If we ever add analytics, an embedded video, a payment provider or anything else that sets cookies, we will update this page first and add a proper consent mechanism before any non-essential cookie is set. We would not add one quietly.

Controlling cookies in your browser

Even though this site sets nothing, you can control cookies generally through your browser settings. All major browsers let you block third-party cookies, clear existing ones, and set site-specific exceptions. Blocking cookies for this site will not affect how it works.
